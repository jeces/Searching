# 번개장터 & 중고나라 실시간 중고 시세 검색 및 Excel 다운로드 웹/앱

번개장터와 중고나라의 중고 상품 매물 가격을 한눈에 실시간 검색하고 비교 분석하며, 검색된 목록을 **Excel(.xlsx)** 파일로 추출할 수 있는 전용 백엔드 서버 연동 반응형 웹/앱 서비스입니다.

---

## 🚀 실행 방법 (How to Run)

### 방법 A. Windows 사용자 (가장 추천! ⭐)
프로젝트 폴더 안의 **`start.bat`** 또는 **`run.bat`** 파일만 더블 클릭하세요!
- 백엔드 크롤링 API 서버(`http://localhost:4000`) 및 프론트엔드 웹 앱(`http://localhost:3000`)이 자동으로 구동되며 브라우저가 즉시 열립니다.

---

### 방법 B. 터미널 수동 실행

```bash
# 1) 필요한 패키지 설치
npm install

# 2) 백엔드 크롤링 서버 실행 (다른 터미널 창)
node server.js

# 3) 프론트엔드 웹앱 실행
npm start
```

서버 구동 후 `http://localhost:3000` 주소로 접속하시면 서비스가 정상 작동합니다.

---

## ✨ 핵심 기능

1. **전용 Express 백엔드 크롤링 API (`server.js`)**
   - 포트 4000번에서 실행되는 전용 API 서버를 통해 실시간 매물 데이터 수집 및 전송
2. **앱 내부 매물 상세 모달 (Product Detail View)**
   - 매물 카드 클릭 시 앱 내부에서 매물 사진, 시세, 상태, 거래 지역, 안전결제 여부, 판매자 정보 및 상세 설명 확인 가능
3. **클릭 기반 실시간 시세 크롤링 새로고침**
   - **[⚡ 크롤링]** / **[지금 다시 크롤링]** 버튼 클릭 시 전용 서버와 통신하여 최신 매물 데이터로 실시간 갱신
4. **통합 시세 분석 & Excel (.xlsx) 저장**
   - 검색어별 평균 권장가, 최저가, 최고가, 전체 등록 매물 수 자동 집계
   - **[엑셀출력]** 버튼 클릭 시 전체 검색 목록을 Excel 파일로 즉시 다운로드
5. **반응형 웹 & 모바일 전용 앱 UI**
   - PC 대화면 및 모바일 스마트폰 화면 지원 (모바일 전용 하단 네비게이션 바 탑재)
