# 번개장터 & 중고나라 실시간 중고 시세 검색 및 Excel 다운로드 앱

번개장터와 중고나라의 중고 상품 매물 가격을 한눈에 실시간 검색하고 비교 분석하며, 검색된 목록을 **Excel(.xlsx)** 파일로 추출할 수 있는 반응형 웹/앱 서비스입니다.

---

## 🚀 실행 방법 (How to Run)

본 서비스는 React + Vite 개발 환경으로 구성되어 있습니다. Node.js (v18 이상 권장)가 설치되어 있어야 합니다.

### 1. 개발 서버 실행 (추천)
터미널에서 아래 명령어를 실행하면 local 서버가 시작되며 브라우저에서 바로 연결됩니다.

```bash
# 1) 패키지 설치
npm install

# 2) 개발 서버 실행
npm run dev
# 또는
npm start
```

실행 후 브라우저에서 `http://localhost:3000` 접속하시면 웹페이지가 바로 열립니다!

---

### 2. 빌드 후 결과물 실행 (dist/index.html)
웹 서버 없이 바로 빌드된 파일(`dist/index.html`)을 확인하거나 배포하려는 경우:

```bash
# 빌드 수행
npm run build
```

빌드가 완료되면 `dist` 폴더 내에 `index.html`과 JS/CSS 자산이 생성되며, 상대 경로(`base: './'`) 설정이 되어있으므로 로컬 웹 서버 또는 `npx serve dist` 명령어로 어디서든 실행 가능합니다.

```bash
# 빌드된 웹사이트 프리뷰 실행
npx serve dist
```

## ✨ 핵심 기능

1. **실시간 크롤링 새로고침 (클릭 시 작동)**
   - 매초 자동조회가 아닌, 사용자가 **[⚡ 실시간 크롤링 새로고침]** 버튼 또는 검색 버튼을 클릭할 때 실시간으로 번개장터/중고나라 데이터를 크롤링 및 갱신합니다.
2. **번개장터 & 중고나라 통합 검색**
   - 두 플랫폼의 최신 매물을 모아서 가격 비교
   - 번개장터 전용 / 중고나라 전용 / 전체 매물 탭 필터링
3. **실시간 시세 분석 다이얼로그**
   - 검색어별 평균 거래 시세, 최저가, 최고가, 등록 매물 수 집계
4. **상세 필터 & 정렬**
   - 가격대(최소~최대) 설정
   - 안전거래(안전결제) 상품만 모아보기
   - 최신순, 낮은 가격순, 높은 가격순, 인기순 정렬
5. **Excel (.xlsx) 리스트 저장**
   - **[Excel 다운로드]** 버튼 클릭 시, 현재 검색/필터링된 목록 전체가 엑셀 파일로 다운로드됩니다. (상품명, 플랫폼, 가격, 상태, 지역, 안전결제 여부, 원문 링크 포함)
6. **반응형 웹 & 모바일 앱 UI**
   - PC 모니터부터 모바일 스마트폰 화면까지 완벽 지원 (모바일 전용 하단 앱 바 탑재)
