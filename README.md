# 번개장터 & 중고나라 실시간 중고 시세 검색 및 Excel 다운로드 앱

번개장터와 중고나라의 중고 상품 매물 가격을 한눈에 실시간 검색하고 비교 분석하며, 검색된 목록을 **Excel(.xlsx)** 파일로 추출할 수 있는 반응형 웹/앱 서비스입니다.

---

## ⚠️ 실행 시 주의사항 (중요!)

컴퓨터 탐색기에서 `index.html` 또는 `dist/index.html` 파일을 **더블 클릭하여 브라우저로 직접 열면(`file://...`) 아무것도 뜨지 않는 흰 화면이 출력됩니다.**

> **원인:** 최신 웹 기술(React / ES Module)은 브라우저 보안(CORS) 규칙상 `file://` 경로 직접 열기를 금지하고 있으며, 반드시 **웹 서버(Local Server)** 환경에서 실행되어야 정상 작동합니다.

---

## 🚀 가장 쉬운 실행 방법

### 방법 A. Windows 사용자 (더블 클릭 실행)
프로젝트 폴더 안의 **`start.bat`** 또는 **`run.bat`** 파일을 더블 클릭하세요!
- 영문 기반 ASCII 스크립트로 구성되어 윈도우 한글 깨짐 오류가 발생하지 않으며, `node_modules` 설치 확인 후 `http://localhost:3000` 개발 서버를 열어 브라우저가 자동으로 실행됩니다.

---

### 방법 B. 터미널(명령 프롬프트 / VS Code / Git Bash) 직접 실행

Node.js(v18 이상)가 설치되어 있는 상태에서 프로젝트 폴더 터미널에 아래 명령어를 입력하세요.

```bash
# 1) 패키지 설치
npm install

# 2) 서버 실행 (자동으로 브라우저 열림)
npx vite --open
# 또는
npm start
```

실행 후 화면에 출력되는 `http://localhost:3000` 주소로 접속하시면 웹페이지가 바로 열립니다!

---

### 방법 C. 빌드 후 실행 (`dist` 폴더)

```bash
# 1) 빌드 실행
npm run build

# 2) 로컬 서버로 dist 실행
npx serve dist
```

## ✨ 핵심 기능

1. **클릭 기반 실시간 크롤링 새로고침**
   - 매초 자동조회가 아닌, 사용자가 **[⚡ 크롤링]** 버튼 또는 **[검색]** 버튼을 클릭할 때 실시간으로 번개장터/중고나라 매물을 수집하고 최신 데이터로 갱신합니다.
2. **번개장터 & 중고나라 통합 검색**
   - 두 플랫폼의 최신 매물을 한눈에 모아서 실시간 가격 비교
   - 전체 / 번개장터 / 중고나라 플랫폼별 탭 필터
3. **실시간 시세 분석**
   - 검색어별 평균 거래 권장가, 최저가, 최고가, 전체 등록 매물 수 집계
4. **상세 필터 & 정렬**
   - 최소/최대 가격 범위 설정
   - 안전결제(번개페이/안페) 상품만 보기
   - 최신순, 낮은 가격순, 높은 가격순 정렬
5. **Excel (.xlsx) 리스트 다운로드**
   - **[엑셀출력]** 버튼 클릭 시, 현재 조회된 중고 매물 목록 전체가 Excel(.xlsx) 파일로 다운로드됩니다. (상품명, 가격, 플랫폼, 상품상태, 거래지역, 안전결제 여부, 원문 링크 포함)
6. **반응형 웹 & 모바일 앱 UI**
   - PC 대화면 및 모바일 스마트폰 완벽 지원 (모바일 전용 하단 네비게이션 바 제공)
